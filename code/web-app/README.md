# Web App

`puck_control.html` is a standalone browser-based BLE control page for the
Smart Puck, matching the BLE service/characteristics defined in
`code/firmware/src/main.cpp` (service UUID `6E400001-...`, RX/TX characteristics).

Open it directly in a Web Bluetooth–capable browser (Chrome/Edge on
desktop or Android) to connect to the puck and send/receive control messages
without needing a native app.
